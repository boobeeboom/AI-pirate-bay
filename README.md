# AI Native Code — Module 1 archive

Статическая архивная копия опубликованных материалов Module 1: **Organize your codebase for agents**.

Сайт: <https://boobeeboom.github.io/AI-pirate-bay/>

В проекте сохранены:

- главная страница, каталог и страница модуля;
- вводная часть `Unit 00`;
- полные приобретённые материалы `Unit 01`, `Unit 02` и видеозапись `Unit 03`;
- 16 иллюстраций и постеров;
- локальный браузер 49 файлов примера из `Unit 01` и 50 файлов из `Unit 02` с поддержкой ссылок на строки;
- исходные архивы `s01_main.zip` и `s02_main.zip`.

Видеозапись `Unit 03` воспроизводится с исходного хранилища автора: файл размером около 275 МБ превышает лимит одного файла GitHub.

Авторизация и покупка отключены. Неопубликованные разделы не добавлялись. Готовая GitHub Pages-сборка находится в `docs/`.

Материалы принадлежат автору курса и предназначены для личного использования владельцем доступа.
