Module 1: Organize your codebase for agents

How do we organize a codebase so a fresh agent can find relevant information, get work done, and benefit from previous sessions? We’ll explore document trees, progressive disclosure, reusable scripts, and control centers. You’ll get written material, source code, and small practical tasks. In two live sessions, I’ll show how I use these ideas in real projects and answer your questions.
